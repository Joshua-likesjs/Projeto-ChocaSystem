# Incubadora Monitoramento - App Mobile

Aplicativo mobile nativo para monitoramento de incubadoras de ovos em tempo real.

## 🚀 Como Executar

### 1. Instalar Dependências
```bash
cd mobile
npm install
```

### 2. Iniciar o Expo
```bash
npm start
```

### 3. Executar em Dispositivo
- **Android**: Pressione `a` no terminal ou escaneie o QR code com o app Expo Go
- **iOS**: Pressione `i` no terminal ou escaneie o QR code com o app Expo Go
- **Web**: Pressione `w` no terminal

## 📱 Funcionalidades

- ✅ Autenticação com Firebase
- ✅ Dashboard em tempo real
- ✅ Monitoramento de sensores
- ✅ Interface nativa e responsiva
- ✅ Navegação fluida entre telas

## 🛠️ Tecnologias

- React Native com Expo
- Firebase Authentication
- Firebase Realtime Database
- TypeScript
- React Navigation

## 📋 Pré-requisitos

- Node.js 16+
- Expo CLI: `npm install -g expo-cli`
- App Expo Go no dispositivo (para desenvolvimento)
